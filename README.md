# The Backrooms (VIruss)

Forge 1.20.1 мод: измерение Level 0.

## Как попасть в Бэкрумс
Нужно, чтобы тебя придавило песком: встань под падающий песок и подожди пару секунд — реальность «накроет» тебя, и ты провалишься на Уровень 0.

## Как выбраться
Поставь блок **Глитч (выход)** и кликни по нему ПКМ — вернёшься в обычный мир на точку спавна.

## Сборка
- Локально: `gradle build` (JDK 17), JAR появится в `build/libs/`
- GitHub: пуш → вкладка Actions → скачай артефакт `backrooms-jar`

JAR кладётся в `.minecraft/mods` (нужен Forge 1.20.1).
